# Deliver: polish

Run this pass after the critic loop, before calling the UI done.

## Cut

Remove what doesn’t serve the feeling or the primary action:

- Extra labels when the visual already communicates
- Nested containers, cards-in-cards, empty chrome
- Gradients, glows, and decorative blobs that aren’t the idea
- Custom buttons/inputs that lose to simpler native ones
- Sections that repeat the same claim in different words
- Page-level marketing headlines on a utility screen
- Duplicate navigation (top + side + in-body) saying the same thing

Less on the screen is usually the upgrade.

## AI tells (checklist, not a ban list)

During refinement only. Keep a pattern if it earns the feeling; replace it if it’s just the default.

**From landing pages (still apply):**

- Generic purple / indigo gradients
- Inter / system-default “AI sans”
- Hero: text left + abstract graphic/orb right
- Glassmorphism, glow, bloom everywhere
- Cards in cards in cards
- Pill-shaped everything
- Too many labels, badges, and mute feature rows
- Fake 3D blobs, orbs, pottery, crystals as decoration
- Helper text on every element
- Custom controls worse than native
- Even, committee-safe spacing with no tension
- Friendly stock illustrations and rounded icon grids
- Identical three-column “features” blocks
- Fake testimonials / logos / metrics

**Product UI extras:**

- Sidebar + topbar + three KPI / stat tiles
- Soft gray dashboard with rounded card grid
- Icon + title + description rows inside an app that already has a nav
- Chip / tag / badge soup
- Gradient mesh or aurora behind product chrome
- Empty-state illustrations that don’t teach the action
- Over-padded settings lists
- Fake avatars, activity feeds, or “team” chrome
- Skeleton loaders that never match the real layout
- Every number in a separate card instead of one dense readout

## Copy

First-pass copy is placeholder. Rewrite every visible string before ship:

- Shorter. Specific. One idea per sentence.
- No “reimagine”, “empower”, “seamless”, “next-generation”, “unlock”, “elevate”.
- Screen titles name the job. Subheads don’t repeat the title.
- Primary action is a verb + outcome, not “Get started” unless that’s truly the action.
- Control labels name the control. Errors name the failure and the next step.
- Don’t invent sample data that could be mistaken for product data.
- Show the final copy to the user so they can rewrite it in their voice.
