# Example

Input: `/mvp-spec a shared receipt inbox for two freelancers who invoice from the same Gmail`

Lock lines (in chat, before files):

1. **Who** — a freelancer who already shares a client inbox with one partner
2. **Job** — see every receipt in one place without forwarding threads
3. **Demo** — two Gmail tabs, one public inbox URL, both drop a receipt, the
   page lists both without either person forwarding
4. **Cut** — accounting integrations, OCR, and "team workspaces"

Then a `plans/receipt-inbox-mvp.md` whose one-sentence summary is:

> A URL two people paste into. Each authorized Gmail drops receipts onto it.
> Proof: both inboxes appear on one page without forwarding.

Non-goals include QuickBooks, seats, and "AI that files your taxes."

First build:

1. Inbox URL with a live list
2. One connected Gmail per person, receipts only
3. Demo script: two accounts, two drops, one page
4. Rehearse §6

The canvas shows those four lock facts, the demo script as the large card,
in vs out, and the four build todos. It does not show a TAM chart.
